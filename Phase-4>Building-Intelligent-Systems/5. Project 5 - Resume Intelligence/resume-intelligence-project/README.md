# Project 5 — Resume Intelligence

## Goal

Bring together the components built in the earlier projects:

```text
Document Processing
        ↓
Text Extraction / OCR
        ↓
Text Cleaning
        ↓
Resume Parsing
        ↓
Structured Resume
        ↓
Resume Analysis
        ↓
Job Description
        ↓
Exact Skill Matching
        ↓
TF-IDF Similarity
        ↓
Embedding Similarity
        ↓
Explainable Match Score
        ↓
Streamlit
```

The application deliberately starts with understandable components rather than
one large model.

## Run

Install dependencies if needed:

```bash
pip install -r requirements.txt
```

Then:

```bash
streamlit run app.py \
  --server.address 0.0.0.0 \
  --server.port 8501 \
  --server.enableXsrfProtection false \
  --server.enableCORS false
```

If port 8501 is already occupied, use 8502.

## OCR dependency

`pytesseract` is a Python wrapper. The system also needs the Tesseract
executable.

Check:

```bash
tesseract --version
```

If the Cloud Lab image already contains Tesseract, no additional setup is
needed.

If you are processing a text-based PDF, Tesseract is not used.

## What the final score means

The score is a similarity/ranking signal generated by the selected formula.

It is NOT:

- probability of candidate success
- proof of candidate quality
- an automated hiring decision

The UI intentionally exposes the component scores so students can inspect
where the final number comes from.

## Reusing earlier projects

This starter is self-contained so it can run without requiring the previous
project folders.

For the final course repo, replace these files with the students' working
versions from earlier projects where appropriate:

- `document_pipeline.py` ← Project 1 document processing
- `resume_parser.py` ← Project 2 parser
- `similarity.py` ← Project 3 matching components
- document-classifier inference ← Project 4

The interfaces should remain small and explicit so the components can be
replaced without rewriting `app.py`.
