# Tutorial 12 — JavaScript for Beginners

## Why This Matters

The goal is familiarity, not a JavaScript course.

## Variables

Python:

```python
name = "Ashish"
```

JavaScript:

```javascript
const name = "Ashish";
```

The syntax differs, but the programming idea is familiar.

## Functions

Python:

```python
def greet(name):
    return "Hello " + name
```

JavaScript:

```javascript
function greet(name) {
    return "Hello " + name;
}
```

## Console

Use:

```javascript
console.log(name);
```

Then inspect the browser developer tools Console.

## Events

Browsers produce events such as click, submit, change, and input. JavaScript can respond to them.

## Try It

Create a button that prints a message to the console, then change a paragraph when it is clicked.
