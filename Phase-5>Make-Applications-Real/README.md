# Phase 5 - Make Applications Real

Phase 5 takes the student's Phase 4 web application and introduces the pieces needed to make it a Minimum Working Product.

The projects progress from understanding databases to SQL, users and authentication, production configuration, deployment, and finally a complete MWP.

## Projects

1. Give Your Application a Database
2. Learn Enough SQL to Work With Your Data
3. Add Users and Authentication
4. Prepare Your Application for Production
5. Deploy Your Application
6. Build Your Minimum Working Product

## Teaching principle

The goal is not to make students production engineers.

The goal is:

> Build the simplest working version of an idea that another person can actually use.

Each project is intentionally small and can be studied independently.
