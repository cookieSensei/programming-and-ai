# Phase 5 Tutorial Index

| # | Tutorial | Main outcome |
|---|---|---|
| 01 | Give Your Application a Database | Understand persistent application data |
| 02 | Learn Enough SQL | Inspect and change stored data directly |
| 03 | Add Users and Authentication | Support individual users and protect data |
| 04 | Prepare Your Application for Production | Separate development configuration from production configuration |
| 05 | Deploy Your Application | Put the application in front of another person |
| 06 | Build Your Minimum Working Product | Combine everything into the smallest useful public product |

## Core progression

```text
Phase 4 application
        ↓
```
