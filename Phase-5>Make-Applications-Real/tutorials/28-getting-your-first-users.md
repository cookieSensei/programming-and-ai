# Tutorial 28 — Getting Your First Users

## Why This Matters

A deployed application is not automatically a product; someone needs to use it.

## Start Small

You do not need thousands of users. Start with one real person, then learn from a few more.

## Test With a Task

Give someone the URL and say what task to accomplish. Observe rather than explaining every click.

## Ask

```text
What did you think this was?
What did you try first?
What was confusing?
Did you complete the main task?
What would you change?
Would you use it again?
```

## Build → Test → Learn

```text
Build
 ↓
Deploy
 ↓
User
 ↓
Feedback
 ↓
Improve
 ↓
User again
```

## Remember

Your first deployed application is not the end. It is the beginning of learning whether the idea is useful.
