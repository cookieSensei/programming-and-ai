# Tutorial 27 — Minimum Working Product Thinking

## Why This Matters

Entrepreneurs often start with a large vision; builders need to find the smallest useful version.

## Reduce the Idea

Ask:

> **What is the one thing the user needs to accomplish?**

For a large platform, the first version might only let a business create a listing and receive an inquiry.

## Core User Journey

```text
User
 ↓
Action
 ↓
System
 ↓
Result
```

## Must Have vs Later

Example:

```text
Must Have
- Create listing
- View listing
- Send inquiry

Later
- Payments
- Analytics
- Notifications
- AI recommendations
- Mobile app
```

## AI Does Not Remove Scope

AI can make implementation faster, but you still have to decide what is worth building first.

## Try It

Write:

```text
My user is:
My user's problem is:
The smallest useful workflow is:
I will deliberately leave out:
```

## Remember

> **A smaller working product teaches you more than a larger unfinished product.**
